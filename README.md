# Renad Eid Borham - 3D Portfolio

An interactive 3D portfolio for Renad Eid Borham, a Computer Science student focused on AI/ML, Generative AI, LLMs, RAG, Agentic AI, backend APIs, and MLOps.

Live site: [renadborham123.github.io/renad-portfolio](https://renadborham123.github.io/renad-portfolio/)

## Tech Stack

- Next.js
- React
- React-three-fiber
- DREI
- GSAP
- Zustand
- Tailwind

## Portfolio Data

The experience, projects, links, downloadable CV, and metadata are personalized from Renad's CV. The original blue sky palette has been replaced with a pink palette.
